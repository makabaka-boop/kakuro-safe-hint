# Kakuro Studio · 数和离线编辑器

用 Svelte + TypeScript 实现的**离线**数和（Kakuro）编辑器与求解器。
重点不是“找到一个填法”，而是严格回答**这盘谜题是否只有一个解**：
横、竖线索各自可满足并不代表全盘唯一，工具会在找到第二个解时立即停止，
并在多解时展示**按行优先字典序最小的两份完整填法**，避免把一个“可能的答案”误称为唯一答案。

谜题页由 `docker compose` 构建并以纯静态站点（nginx）提供。

## 功能

### 编辑器（`#/editor`）

- 棋盘至多 10×10，白格不超过 28；单击选择、双击切换墙/白；
- 墙格右上写**横线索**、左下写**竖线索**，线索为 3～45 的整数；
- 每条横/竖连续白格段长度限制 **2～6**；
- 实时结构校验：每个白格必须**恰属于一条横线与一条竖线**，
  并检测越界线索、悬空线索（墙格带线索但旁边没有白格）、缺线索、段长非法；
- 撤销/重做、尺寸调整、清空、JSON 导入/导出、一键发布到谜题页（localStorage）。

### 唯一性分析（核心）

点击“分析唯一性”后：

1. **候选组合传播**：每条线段枚举“互异数字 1～9、和为线索”的组合，
   用二分图完美匹配判定每个位置在当前候选域下可取的数字，队列式收缩各白格候选；
2. **回溯搜索**：传播停止后，严格按行优先顺序、数字从小到大分支
   （保证找到的前两个解就是字典序最小的两个），每条分支先传播再递归；
3. **找到第二个解立即停止**，分类为：
   - `无解（unsat）`：不存在任何合法填法；
   - `唯一解（unique）`：恰好一份完整填法，展示该见证；
   - `多解（multiple）`：至少两份填法，展示字典序最小的两份见证；
   - `搜索超限（limit）`：节点数触顶时如实报告，绝不武断给结论。
4. **线索（或任何结构）一改，先前结论立即标记失效**（横幅变暗 + 失效提示），
   需重新分析；进行中的旧搜索结果会被丢弃。
5. “显示候选”可在棋盘上查看每个白格在当前传播阶段剩余的候选数字（1～9 九宫格，
   被排除的数字划线）；侧栏显示选中格的候选；谜题页求解后点格也可查看。

### 谜题页（`#/puzzle`，Compose 提供）

- 只读展示线索，玩家填 1～9；
- 本地实时检测：同线重复标红、填满但和不符描边、完成计数；
- 可载入编辑器发布的盘面、粘贴 JSON 或使用内置示例；
- 可运行同一个求解器查看分类与两份见证、查看单格候选。

## 技术与目录

```
src/
  lib/
    types.ts          # 盘面模型与常量（10×10 / 28 白格 / 线长 2~6 / 和 3~45）
    validation.ts     # 结构校验：白格恰属一横一竖、段长、线索范围、悬空线索
    combinations.ts   # (长度, 和) -> 互异数字组合（记忆化 + 剪枝）
    solver.ts         # 候选组合约束传播（二分图匹配）+ 行优先回溯，遇第二解停止
    stores/boardStore.ts  # Svelte 仓库：编辑、撤销重做、异步求解与失效管理
    sample.ts         # 内置唯一解示例
    router.ts         # 离线 hash 路由
  components/
    BoardGrid.svelte      # 可编辑棋盘（墙/白、线索输入、候选叠加层）
    WitnessGrid.svelte    # 见证填法的只读小网格
  pages/
    EditorPage.svelte
    PuzzlePage.svelte
```

求解器与 UI 解耦（纯 TypeScript，无 DOM 依赖），可直接单测与复用。

## 开发

```bash
npm install
npm run dev        # 本地开发（Vite）
npm run build      # 生产构建到 dist/
npm run typecheck  # svelte-check 严格类型检查
npm test           # Vitest：小盘面全枚举交叉核对
```

## 测试如何保证“不误称唯一”

`src/lib/solver.test.ts` 内有一个**与求解器完全独立的朴素全枚举器**
（按行优先枚举所有 1～9 赋值，逐线段检查不重复与和，线段闭合时剪枝），
用它对大量小盘面做交叉核对：

- 2×2 白格块：线索 3/4/5/10/15/16/17 的 **2401** 个组合全量比对分类与前两个见证；
- 2×3 白格块：**243** 个抽样组合全量比对；
- 7 白格非矩形阶梯盘：结构校验 + 抽样组合全量比对；
- 组合表：所有长度 2～6、和 3～45 的组合均满足长度/互异/取值/和；
- 非法盘面：线索越界、悬空线索、段长 1、缺线索、无白格均被拒；
- 候选查看：见证数字一定在传播后候选内，传播可独立单值化的盘面被识别。

## Docker Compose（提供 puzzle 页面）

```bash
docker compose up --build
# 谜题页  http://localhost:8080/#/puzzle
# 编辑器  http://localhost:8080/#/editor
```

镜像构建阶段会执行 `npm run build` 与 `npm test`；运行阶段为只读 nginx，
hash 路由使两个页面在任意路径刷新都可用，不需要服务端特殊配置。
